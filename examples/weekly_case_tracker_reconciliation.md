# SOP: Weekly Case Tracker Reconciliation

**Date Created:** 2026-11-11

**Summary:**
Compare the system export against the team tracker and correct mismatches before the weekly report.

**Tools Used:**
Excel, case management system export

**Steps:**
1. Export open and decided cases from the case management system
2. Open the team tracker in Excel
3. Match records by Case ID and list cases missing from either source
4. Check status and decision dates for every matched case
5. Correct keying errors and log each fix in the tracker notes

**Responsible Role:**
QA Analyst

**Frequency:**
Weekly
